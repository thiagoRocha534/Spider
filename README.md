# Spider Som e Filme -> Controle de atendimentos, orçamentos e produtos

Front-end mockado (sem backend): os dados vivem em memória, no próprio app,
para servir de referência visual e de fluxo. Login de demonstração em
`src/services/auth.ts`.

# Tecnologias usadas

- React query

- React icons

- Material UI

- Tailwind

- Tanstack table

# Como instalar

```shell
  - npm install
  - npm run dev
```
